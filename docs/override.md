# override 合并规则

WebUI（`webui/merge.js`）与本文的权威规范。实现、测试与本文冲突时以本文为准。背景见 [`decisions.md`](decisions.md) #4。

## 文件

| 文件 | 位置 | 维护者 |
|---|---|---|
| `base.yaml` | 模块目录，随模块升级替换 | 模块 |
| `override.yaml` | 数据目录 `/data/adb/mihomo-ksu/` | 用户（通过 WebUI） |
| `config.yaml` | 数据目录，mihomo 实际加载 | WebUI 生成：`merge(base, override)` |

override 是一个 mihomo 配置片段，只写与 base 不同的部分。

## 合并步骤

按顺序执行：

1. **深度合并**：除特殊键（`prepend-rules`、`append-rules`）外，override 的每个键按下面的规则合并到 base 上。`x-provider-defaults` 同样参与这一步，也就是说 override 可以修改订阅默认字段。
2. **订阅补齐**：用第 1 步得到的 `x-provider-defaults`，补齐 `proxy-providers` 中每个条目缺失的字段。
3. **规则插入**：在第 1 步得到的 `rules` 上处理 `prepend-rules` / `append-rules`，然后从结果中删除这两个键。

### 1. 深度合并

| base 中的值 | override 中的值 | 结果 |
|---|---|---|
| map | map | 递归合并：逐键套用本表 |
| 任意 | 标量、数组、`null` | override 整体替换 |
| 不存在 | 任意 | 取 override |
| 任意 | 不存在 | 保留 base |

- 数组一律整体替换，包括 `rules`、`proxy-groups`、`tun.dns-hijack`、`dns.fake-ip-filter` 等。要在 base 的数组上增减条目，只能写出完整的新数组。唯一的例外是规则，见第 3 步。
- `null` 不做特殊处理，按标量替换；mihomo 把它当作未设置。
- base 的代理组使用 `include-all`，新增的订阅会自动进入这些组，通常不需要改 `proxy-groups`。

### 2. 订阅补齐

对 `proxy-providers` 中的每个条目 `<name>: <entry>`：

- 结果 = `x-provider-defaults` 与 `<entry>` 深度合并（规则同第 1 步），`<entry>` 中已写的字段优先。例如条目只写了 `health-check: {url: ...}`，`health-check` 的其他字段仍从默认值补齐。
- 条目没写 `path` 时，生成 `./providers/<name>.yaml`。
- `<name>` 会用于文件路径，不能包含 `/`，否则报错。
- `<entry>` 必须是 map（例如只写了名称、没有写任何字段时为 `null`），否则报错。
- `x-provider-defaults` 本身原样保留在 `config.yaml` 中，mihomo 忽略不认识的顶层键。

通常每条订阅只需要写 `url`。

### 3. 规则插入

- `prepend-rules`：插入到 `rules` 的最前面，保持自身顺序。
- `append-rules`：插入到最后一条 `MATCH` 规则之前；`rules` 中没有 `MATCH` 时追加到末尾。
- 两者都基于第 1 步的结果：如果 override 同时写了 `rules`（整体替换），先替换，再插入。
- 两个键都必须是数组，否则报错。

## 模块管理的字段

以下字段被模块的脚本或 WebUI 依赖，override 中出现任意一个都报错（"该字段由模块管理"），不生成 `config.yaml`：

| 字段 | 依赖方 |
|---|---|
| `external-controller` | WebUI 调用 API、面板链接固定使用 `127.0.0.1:9090` |
| `secret` | 由 `secret` 文件经环境变量传入，override 中的值会被覆盖而不生效（decisions #7） |
| `external-ui` | 面板固定安装在数据目录的 `ui/`（decisions #6） |
| `tun.device` | `ctl.sh` 的热点 FORWARD 规则使用网卡名 `Meta` |

## 输入与输出

- `override.yaml` 不存在或为空时，结果等于 base。
- override 的根必须是 map，否则报错。
- 任何报错都不生成 `config.yaml`，保存流程据此拦截（见 plan C5）。
- 生成的 `config.yaml` 第一行是注释 `# Generated by the mihomo-ksu WebUI from base.yaml + override.yaml; do not edit.`。base 中的注释和锚点不保留（锚点展开为实际值）。

## 示例

override：

```yaml
proxy-providers:
  airport:
    url: https://example.com/sub?token=xxx
  backup:
    url: https://example.org/sub
    interval: 3600

prepend-rules:
  - DOMAIN-SUFFIX,example.com,DIRECT

append-rules:
  - DOMAIN-SUFFIX,windowsupdate.com,DIRECT

dns:
  nameserver:
    - https://1.1.1.1/dns-query
```

结果中：

- `proxy-providers.airport` = `x-provider-defaults` 的全部字段 + `url` + `path: ./providers/airport.yaml`；`backup` 的 `interval` 为 3600，其余同理。
- `rules` = `DOMAIN-SUFFIX,example.com,DIRECT`、base 的规则（不含 `MATCH`）、`DOMAIN-SUFFIX,windowsupdate.com,DIRECT`、`MATCH,Final`。
- `dns.nameserver` 整体替换为一项；`dns` 的其他字段保留 base 的值。
